# Bundled fonts

Manrope variable (weights 200–800) is the primary interface and brand face. IBM Plex Mono Regular is reserved for versions, identifiers and technical labels. Both are bundled for offline use; retain their accompanying SIL Open Font License files when redistributing.

Sources, retrieved 10 October 2026:
- [Manrope source and license](https://github.com/google/fonts/tree/main/ofl/manrope)
- [IBM Plex Mono source and license](https://github.com/google/fonts/tree/main/ofl/ibmplexmono)

The wordmark uses Manrope at weight 650, tightened by 0.015em and converted to SVG paths. Logo rendering does not depend on a font installation. Use the supplied logo assets rather than retyping the wordmark.
